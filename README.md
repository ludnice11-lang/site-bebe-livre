# Bebê Livre

Estou aprendendo programação e construí este projeto para praticar.

Escolhi falar sobre um assunto que conheço bem: a **educação**. O site fala do desenvolvimento do bebê de 0 a 3 anos, com base na abordagem Pikler e em outras pedagogias que respeitam o tempo e a autonomia da criança.

## Veja o site

[Clique aqui para abrir o Bebê Livre](https://ludnice11-lang.github.io/site-bebe-livre/)

## Linguagens que usei

- **HTML** para a estrutura e o conteúdo das páginas
- **CSS** para as cores, a organização na tela e as animações
- **JavaScript** para o botão de voltar ao topo
